# Veyra 1.4.3 本地测试版

2026-09-20，用户授权本地打包测试，尚未公开发布。

包含 1.4.2 发布后当前分支的修复：

- 保留此前 `7a3dfae` 的补帧基线，并修复拖动窗口边角时的 UI 线程栈耗尽崩溃。保留用户选择的补帧倍率，不再自动改成较低倍率。
- 拆分主窗口与设置面板的高栈占用消息处理；真实鼠标拖动、采集预览及 NR + DLSS 6X / XeSS 4X 反复缩放已通过本机短测。
- 保留文件播放有限追赶、逐子帧状态读取及对应 GPU fence 保护；无收益或存在资源安全问题的后续实验已回退。没有加入额外 35/50ms 等待。

- 修正 XeSS / DLSS 切换弹回、XeSS 2X 后无法切到 4X 的能力缓存问题；运行中切换失败恢复原设置。
- 修正异步准备帧的 XeLL 标记周期，回归拖动、窗口缩放、历史重置和连续切换。
- 调整 DLSS / XeSS 调度成本统计及实时呈现相位，处理错误降档、补帧受限与节奏异常路径。
- 修正压缩采集解码参考链、帧身份、EAGAIN 重送、重排时间戳和 D3D11 资源释放。
- 修正字幕弹窗闪退式关闭、字幕布局和样式缓存；保留参数独立还原、跨屏与调色对比等此前修复。
- 包含当前分支的采集音频恢复、NR + RTX Video HDR 截图、音量键及同步相关修复。
- 补充独立 XeSS 提交计数，避免通用 GPU 日志的 0 被误读为没有生成帧。

## 测试重点与已知边界

固定 6X 的均匀呈现尚未解决。本机 RTX5070、p001 原生 4K60、NR1080、4K 输出的近期对照约 295–303 次提交/秒，仍有约 16.8ms 长间隔；不能据此宣称稳定 360fps 或无卡顿。此素材原生 4K，实际超分计算被旁路，不代表叠加超分负载的成绩。2X/4X 针对性短测约 120/240 次提交/秒，仍需用户实际体验验收。

请重点测试 DLSS 4X/6X 与 XeSS 2X/4X 反复切换、采集持续运行、拖动和跨屏。
本机 RTX5070 的针对性回归已通过；不代表所有显卡、驱动或 GC551/GC573 实卡已验收。
YUY2 50fps 的日志和合成测试有补帧输出，但用户所述观感及与 PotPlayer 的清晰度差异尚未定因。
软件提交 FPS 不等于屏幕实际刷新率；未进行光学端到端延迟测量。

保留 RTX Video HDR、原有帧同步与 PS5 功能。NVIDIA FSR4 实验仍撤回。
增强运行库均沿用既有身份，属于实验集成，不代表厂商认证或合作。
首次使用全部增强默认关闭，包内不含个人设置、凭据或测试媒体。
